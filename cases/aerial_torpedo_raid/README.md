# 案例 · 飞机投雷突袭（瓜岛 10/25 fork 次日海空战）

> 模型：`src/aerial_torpedo_fem.py`（飞机投雷有限元推算）
> 方法论：先算**干净几何底**（仅投弹散布＋目标匀速机动），再用实测锚点反推
> **干扰因子**（CAP 拦截 / 高炮命中 / 鱼雷可靠性 / 投弹距离误差）。
> 本案例把模型套到本仓库 `mc_fem.py` 的 **gambler（fork）场景 1000 局次日态势**上，
> 验证用户三段链——**拂晓一式陆攻突袭撤走的美残队 → 金凯德追击日战列舰 → 南云反杀金凯德**——的合理性。

## 起点态势（继承自 final1000.json，gambler 场景）

| 资产 | 美方（10/25 02:00） | 日方 |
|---|---|---|
| 水面 | 战力损失 51.96%、中位沉 3 艘；两舰 BB 退出战斗率 67%；驱逐舰 5 寸 **100% 打空**、亚特兰大级 91% 打空 ⇒ **水面防空核心清零** | 战力损失 9.81%，战列舰近乎零战沉 |
| 岸基航空 | 亨德森被压制为"双方均不可使用" | 拉包尔一式陆攻（~30-40 架可出）、布因 204 空零战完好 |
| 舰载航空 | 只剩企业号 | 南云机动部队打完**不丧失战斗力**（消耗≈圣克鲁斯一半） |

⇒ 美方次日空中力量只剩"一艘航母甲板"，且企业号 CAP 被三线拆用（救残队 / 守自己 / 钓鱼打日战列舰）。

## 三段链推演结果

### 场景 A · 拂晓一式陆攻（G4M）突袭美残队
- 目标：夜战重创 BB/CA，Vt≈8 kt，**无 CAP**（企业号 150nm+）、**无高炮弹药**。
- 结果：单雷干净命中 98.9%；18 架出击、战损 3%、有效投雷机 14.8、**期望命中 11.74 雷**、沉没概率 **99.9%**。
- ⇒ **突袭高效，证实"突袭效能"成立**。残队被补刀，金凯德被迫以航母填补防空真空。

### 场景 B · 南云 Kate 突击 fork 企业号（CAP 减半）
- 目标：CV 30 kt 机动；fork 下因水面清零→企业号 CAP 减半、高炮齐全。
- 结果：40 架出击、战损 42%、有效投雷机 10.4、**期望命中 7.97 雷**、沉没概率 **98.6%**。
- ⇒ **南云反杀金凯德的"牌"在 fork 下远超史实**。

### 场景 B' · 对照：史实企业号（满 CAP）
- 同样 40 架 Kate，但满 CAP ⇒ 战损 62%、有效投雷机仅 3.3、期望命中 2.55、沉没 46.9%。
- 与圣克鲁斯史实（企业号重创未沉、大黄蜂沉）量级一致 ⇒ **模型标定可信**。

## 结论（结构）

1. **干净几何底极高**（CV≈96%、残队BB≈99%）证明：匀速/低速大舰是鱼雷机好靶子；"打不中"主要来自战斗投弹成功率与可靠性，而非几何——这跟 `torpedo_fem.py`（DD 直航雷）的结论同构。
2. **三段链自洽**：A 高效（残队无弹无 CAP）→ 金凯德以航母追日战列舰 → 南云以保全之机动部队反杀企业号。fork 的"水面清零"是整条链的物理前提。
3. **与史实反转的根因**全部回溯到一夜炮战：美方水面清零 → 亨德森瘫痪 → 制空权翻转 → 南云反杀概率从史实 ~47% 升到 fork ~99%。

## 诚实边界

- 航空作战不在 `mc_fem.py` 内，本案例空战结论＝结构化推演＋FEM 几何，非蒙卡背书；
- `combat_drop` 与战损线性模型是**最软的一环**，由圣克鲁斯/中途岛锚点反推，非独立实测；
- "整体改写结局 12-18%"是战略走向档，非"次日必反杀"逐场预测（见 `docs/model_applicability.md` 铁律 #17）。
