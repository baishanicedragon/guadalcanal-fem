## 关键结论

1. **① 不可复现**：当前工作区代码（无论占位鱼雷②还是 FEM 鱼雷③）都跑不出 51.96%。②（47.83%）与①（51.96%）仍差 4pp，说明①来自**比 09-24 当前代码更早**的一个代码版本——该版本在会话中被多次改动（is_jp 修复、speed_gun_factor 接入、穿透模型等）且**无 git / 无 .bak**，已被覆盖，不可重建。
2. **铁律 #16 实证**：同一模型换版本，结论漂 40%+（相对）。文档脚注声明的"源"已失效。
3. **能复现的只有②③**：③（FEM 标定版）是 2026-09-24 重跑落盘的 `output/final1000.json`（30.25%），是当前**唯一应被引用的基线**。
