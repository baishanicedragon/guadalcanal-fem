# 案例：塔拉瓦 1943 末 · 联合推演（基于 FEM 系统）

## 一、本案例的定位

这不是独立模型，而是**本仓库三个 FEM 子模型的联合战役编排**：

| 子模型 | 承担的本战役阶段 |
|---|---|
| `aerial_torpedo_fem.py` | P0 金星零战护航陆攻反击、P3 拂晓陆攻袭慢速本队 |
| `aircraft_dogfight_fem.py` | P0/P3 空战交换比（fork 金星零战 vs US_fork，单场 1.10 / 战役 1.78） |
| `torpedo_fem.py` | P2 第二舰队九三式夜战、P5 双方潜艇互攻 |
| `mc_fem.py` 标定锚 | P2 夜战胜负基准（10-25 fork 30.25% 美损） |

编排文件：`src/joint_tarawa_wargame.py`（蒙特卡洛 n=500, seed=42，可复现）。

## 二、战役序列（用户给定的"大战"）

```
[P0] 美军空袭塔拉瓦；日本以金星零战护航陆攻反击
[P1] D+4 美军主队上岛；近海分【拦截队】(挡救援) 与【炮击队】(轰岛)
[P2] 日本模仿 1942-10-25：第二舰队(大和/武藏加强) 南云指挥 夜间水面战
[P3] 拂晓：其他地域集结陆攻(含银河/火星发动机) + 金星零战 袭慢速战列舰本队，诱美航母空战
[P4] 小泽跨越轰炸：航母起飞后即后撤离美打击范围，飞行员退岸加油次日再战
[P5] 双方潜艇互相前进互攻对方舰队
[P6] 日本以【丁型(松型)驱逐舰 + 舰队潜艇】撤运塔拉瓦残兵
```

**日本此战方针（用户 2026-09-24 最终裁定）**：杀伤美军舰机 + 撤出守军，**不夺回塔拉瓦**。
双方都有路可退、双方均用雷达 → 不歼灭、分「沉没 / 撤退」。

## 三、关键标定常量（均来自已落盘子模型，铁律 #16：引用带版）

- 空战交换比 `EXCH_DOGFIGHT = 1.10`（金星零战 vs US_fork F6F，fork 1943 状态）
- 满 CAP 入侵舰队 `combat_drop = 0.22`（打不沉核心，仅重创）
- 慢速本队 CAP 稀薄 `combat_drop = 0.55`
- DD 直航雷：18km/20kt/N=9，`per-any≈0.44`，九三式可靠 `0.80`
- 夜战损失基准（双方可撤退+用雷达）：美拦截队 0.34 / 日 DD 0.15
- 撤运：丁型驱逐舰 18 艘 ×250 人 + 舰队潜艇 12 艘 ×110 人 = 单航次 4,500+ 上限

## 五、解读（与 fork 长期影响咬合）

- **战术层**：日本达成"杀伤 + 撤运"目标——美军伤亡与舰损显著高于史实塔拉瓦（史实仅 1 CVL 空袭重创 + 1 CVE 潜艇沉），约半数守军被撤出。
- **战略层**：岛仍被夺；且日航母机 76 架损失不可补充（铁律 #9/#11：工业/人口曲线不变），恰好吃掉 fork 最宝贵的精英飞行员预备队 → **反而缩短喘息期**，与 §8.3c「金星零战买时间不买胜负」、§9.6「中太平洋三弱汇聚」完全咬合。
- **承重墙**：日本"经得起交换"吗？挂钩 `aircraft_dogfight_fem.py`——fork 交换比仅 1.10（局部均势甚至日优），但**美军可补、日本不可补**。只要这条成立，战术赢、战略输就稳。

## 六、诚实边界（须声明）

1. 战役数量乘数（日×1.3 / 美×0.8）、跨越轰炸双波次、潜艇命中率均为**建模假设非硬事实**。
2. 守军撤运率（evac_rate 15–70%）由美封锁压力驱动，属参数估计；丁型驱逐舰/潜艇运兵量级取史实撤运任务量级（250/110 人），非精确档案值。
3. **航空闭环操控仍在模型外**：空战结论来自 `aircraft_dogfight_fem` 的开环几何＋PQF 参数，非蒙卡对单场飞行的背书。
4. 所有引用数字须带版本（2026-09-24 版子模型）——铁律 #16。
