# 案例：塔拉瓦 1943 末 · 联合推演（基于 FEM 系统）

## 一、本案例的定位

这不是独立模型，而是**本仓库三个 FEM 子模型的联合战役编排**：

| 子模型 | 承担的本战役阶段 |
|---|---|
| `aerial_torpedo_fem.py` | P0 金星零战护航陆攻反击、P3 拂晓陆攻袭慢速本队 |
| `aircraft_dogfight_fem.py` | P0/P3 空战交换比（fork 金星零战 vs US_fork，单场 1.10 / 战役 1.78） |
| `torpedo_fem.py` | P2 第二舰队九三式夜战、P5 双方潜艇互攻 |
| `mc_fem.py` 标定锚 | P2 夜战胜负基准（10-25 fork 30.25% 美损） |

编排文件：`src/joint_tarawa_wargame.py`（蒙特卡洛 n=500, seed=42，可复现）。

## 二、战役序列（用户给定的"大战"）

```
[P0] 美军空袭塔拉瓦；日本以金星零战护航陆攻反击
[P1] D+4 美军主队上岛；近海分【拦截队】(挡救援) 与【炮击队】(轰岛)
[P2] 日本模仿 1942-10-25：第二舰队(大和/武藏加强) 南云指挥 夜间水面战
[P3] 拂晓：其他地域集结陆攻(含银河/火星发动机) + 金星零战 袭慢速战列舰本队，诱美航母空战
[P4] 小泽跨越轰炸：航母起飞后即后撤离美打击范围，飞行员退岸加油次日再战
[P5] 双方潜艇互相前进互攻对方舰队
[P6] 日本以【丁型(松型)驱逐舰 + 舰队潜艇】撤运塔拉瓦残兵
```

**日本此战方针（用户 2026-09-24 最终裁定）**：杀伤美军舰机 + 撤出守军，**不夺回塔拉瓦**。
双方都有路可退、双方均用雷达 → 不歼灭、分「沉没 / 撤退」。

## 三、2026-09-24 模型订正（用户多轮指出）

1. **打击机队补算**：原版 P4 只解算护航战斗机 vs CAP 的空战交换，舰攻/舰爆对目标的雷击/轰炸从未解算 ⇒ 双方航母几乎无损。现按 `aerial_torpedo_fem` 开环几何解算舰攻（雷击）+ 舰爆（俯冲轰炸，2 弹折 1 雷毁伤），命中泊松摊到目标群（每舰 ≥3 沉 / ≥2 重创）。陆基轰炸机（P3）仍按场景设定打慢速本队。
2. **载机状态估计（用户口径＋长期影响 §9.2/9.3/H2/§6.4c）**：
   - 瑞凤 36 机＝全战斗机，专职直卫第二舰队，**不进打击包**（CAP 0.35）
   - 大凤：fork 修理释放（战沉≤2.6%/结构≤11.5% ⇒ 船坞不再被修理积压占用，铁律 #8 反向兑现）⇒ 新造左移 1-2 季度 ⇒ 1943 Q3 末入列【假设】，~60 机×0.85
   - 伊勢/日向改装舰×2（H2"史实状态＋2 艘改装舰"，25 节）：2×35 机×0.85
   - 信浓：fork 加速但 1943-10 才下水 ⇒ 赶不上本战（收益在 1944）
   - ⇒ **打击包 ≈ 474 机**（护航金星零战 + 天山/彗星级舰攻舰爆）
3. **跨越轰炸方针二选一（用户指定）**：`bb_line` = 打受损战列舰，打完就撤；`cv_first` = 有机会先怼美航母（放血多、自损也大）。

### 方针对比（n=250/方针，seed=42）

| 方针 | 美CV/CVL损 | 美BB损 | 美CA损 | 美舰损合计 | 美机损 | 日机损 | 日CV损 | 撤出% |
|---|---|---|---|---|---|---|---|---|
| bb_line 打残舰就撤 | 0.48 | **5.00（全灭）** | 6.86 | **14.34** | 116.6 | **145.0（27%池）** | 0.06 | 52.6% |
| cv_first 先打航母 | **4.18** | 2.62 | 1.00 | 9.80 | 188.0 | **254.1（48%池）** | 0.10 | 52.6% |

**结论**：单场"杀伤+撤运"目标下 **bb_line 效率高 2.6 倍**（美舰损/日机损 = 0.099 vs 0.039 艘/架）；cv_first 的独特收益是拆掉美军进攻之臂（4.2 flattop ⇒ 美中太平洋航空攻击力数月难复），但一场烧掉 48% 机池（铁律 #9/#11），不可常态化。撤运率两者相同（各削封锁的一条腿）。**fork 最优解＝混合方针（bb_line 主体 + P3 引开 CAP 后对暴露 CV 机会补刀）**。

## 四、关键标定常量（均来自已落盘子模型，铁律 #16：引用带版）

- 空战交换比 `EXCH_DOGFIGHT = 1.10`（金星零战 vs US_fork F6F，fork 1943 状态）
- 满 CAP 入侵舰队 `combat_drop = 0.22`（打不沉核心，仅重创）
- 慢速本队 CAP 稀薄 `combat_drop = 0.55`
- DD 直航雷：18km/20kt/N=9，`per-any≈0.44`，九三式可靠 `0.80`
- 夜战损失基准（双方可撤退+用雷达）：美拦截队 0.34 / 日 DD 0.15
- 撤运：丁型驱逐舰 18 艘 ×250 人 + 舰队潜艇 12 艘 ×110 人 = 单航次 4,500+ 上限

## 六、解读（与 fork 长期影响咬合）

- **战术层**：日本达成"杀伤 + 撤运"目标——美军伤亡与舰损显著高于史实塔拉瓦（史实仅 1 CVL 空袭重创 + 1 CVE 潜艇沉），约半数守军被撤出。
- **战略层**：岛仍被夺；且日航空机 254 架损失（48% 池）不可补充（铁律 #9/#11：工业/人口曲线不变），恰好吃掉 fork 最宝贵的精英飞行员预备队 → **反而缩短喘息期**，与 §8.3c「金星零战买时间不买胜负」、§9.6「中太平洋三弱汇聚」完全咬合。
- **承重墙**：日本"经得起交换"吗？挂钩 `aircraft_dogfight_fem.py`——fork 交换比仅 1.10（局部均势甚至日优），但**美军可补、日本不可补**。只要这条成立，战术赢、战略输就稳。

## 七、诚实边界（须声明）

1. 战役数量乘数（日×1.3 / 美×0.8）、跨越轰炸双波次、潜艇命中率、大凤提前入列（1-2 季度）、二线航空队×0.85、瑞凤 36 机直卫、波次协同折扣 0.75 均为**建模假设非硬事实**。
2. 守军撤运率（evac_rate 15–70%）由美封锁压力驱动，属参数估计；丁型驱逐舰/潜艇运兵量级取史实撤运任务量级（250/110 人），非精确档案值。
3. **航空闭环操控仍在模型外**：空战结论来自 `aircraft_dogfight_fem` 的开环几何＋PQF 参数，非蒙卡对单场飞行的背书。
4. **cv_first 的美 flattop 高损失（4.18/8）对应 maximum-effort 打击**：敏感参数为 `JP_DROP_BASE`（fork 投弹基值 0.60）与 `cap_coverage`；若美 CAP 实际更厚则损失回落。
5. 所有引用数字须带版本（2026-09-24 版子模型）——铁律 #16。
