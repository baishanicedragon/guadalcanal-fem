# 案例：1904–1945 战列舰炮战命中数据集与假说检验

本目录是仓库的**第一个案例（case）**——工作区中"其他汇总的战舰炮击相关数据"：
一份清洗自维基百科战史条目的**战列舰被命中记录**，以及一份检验

> **"头 5–10 次命中决定战局与被击中战舰命运"**

假说的分析脚本。

它与 `src/` 的 FEM 模型互补：FEM 回答"给定条件下命中率的**概率**"，
本数据集回答"历史上真实命中**如何决定命运**"——两者共同构成"先算模型、再用现实校正"的两端。

---

## 文件

| 文件 | 内容 |
|------|------|
| `dataset.py` | `DATASET`：1904–1945 共 56 条战舰被命中记录（黄海 / 对马 / 科罗内尔 / 福克兰 / 多格尔沙洲 / 日德兰 / 卡拉布里亚 / 梅尔斯埃尔凯比尔 / 达喀尔 / 丹麦海峡 / 俾斯麦最后一战 / 卡萨布兰卡 / 两次瓜岛 / 北角 / 苏里高 / 萨马岛）。字段含 `total_hits` / `main_hits`(≥12in) / `decisive_hits` / `critical_loc` / `outcome` / `decided_by_10`。 |
| `analyze.py` | 检验假说：按 `decided_by_10` 分类（支持 / 反例 / 部分支持 / 无法判定），统计"决定性命中数"分布，输出 7 张 SVG 图表 + 自包含 HTML 报告。纯标准库，无第三方依赖。 |

### 字段口径（关键）

- `decided_by_10=True`：支持"5–10 发决定论"（≤10 发内命运已定：沉没 / 丧失战斗力 / 被迫撤出）。
- `decided_by_10=False`：反例（5–10 发区间内命中仍未决定命运，或需 >10 发才决定 / 命中多仍存活）。
- `decided_by_10="partial"`：部分支持（决定性关键命中发生早，但总命中数大或结局被推迟——补刀效应）。
- `decided_by_10=None`：无法判定（命中 <5 发未达检验区间、非炮战决定等）。

> **口径与补刀辨析**（本数据集的方法论核心）："全部命中"≠"大口径命中"≠"决定性命中"。
> 决定命运的是大口径穿甲弹 / 要害命中（司令塔、弹药库、舵机、火控、动力），而非命中总数。
> 幸存反例的机制 = 防御厚度 + 损管 + **弹药性质** + 命中位置运气（如萨马岛大和 6 发全中却过穿未爆）。

## 核心统计（来自 dataset.py）

- 命运已定且能识别决定性命中的记录中，**≤10 发内决定命运占 ~85%**，中位决定性命中数 **2 发**、均值 ~3.6 发。
- 严格支持率（支持 / 支持+反例）≈ 50%；计入"部分支持"后支持面 ≈ 75%。
- 结论：**"头 5–10 次命中决定战局"成立的前提是命中质量（弹种 × 部位 × 口径 × 穿透），而非命中数量本身。**
