# 模型适用性（Applicability & Limitations）

本文件回答一件事：**我们这个 FEM 模型，到底能用在哪、不能用在哪、边界在哪。**
推演结论的可信度，永远不超过"输入参数 + 史实锚点"的可信度。

---

## 一、适用（In scope）

| 维度 | 范围 |
|------|------|
| **时代 / 对象** | 1939–1945 战列舰 / 重巡 / 驱逐舰的**水面炮战与鱼雷战**，尤其 IJN vs USN 所罗门夜战（瓜岛、萨沃、塔萨法隆加等）。 |
| **平台假设** | 开阔水域、**匀速直线运动**（线列对射 / 直线雷击）。这正是二战模拟火控计算机（rangekeeper）的基本假设。 |
| **弹道标定** | 用真实弹道表：US 16"/45 Mk6 + AP Mk8（MV 701 m/s）、JP 46cm Type94 + 91 式 AP（MV 780 m/s）。 |
| **能比较的问题** | "在给定装备 / 训练 / 夜战条件下，命中率与战损的**概率分布**"；或"同口径不同火控 / 照明 / 训练"下的差异比较。 |
| **飞机投雷几何** | **已纳入（开环）**：`aerial_torpedo_fem.py` 以"投弹方位散布 + 目标匀速机动 + 鱼雷直航"算干净命中底（900 m 投弹：CV≈96%、低速 BB≈99%），再用锚点反推战斗投弹成功率 combat_drop 与战损。覆盖九一式航空鱼雷、九七舰攻、一式陆攻。 |
| **飞机近距空战（dogfight）** | **已纳入（开环）**：`aircraft_dogfight_fem.py` 以"干净性能底（能量机动 Boyd 1966：Es=V²/2g+Vs；Ps=V(T−D)/W；回转机动 ω）＋ 飞行员质量因子 PQF ＋ 纸面性能达成率 spec ＋ 武器致命性"算 1v1 交换比。覆盖 F6F/F4U/A6M5/金星零战，及 1942 fork（日本赢瓜岛）背景下的 1943 中太平洋力量对比。 |
| **联合战役编排（composite）** | **已纳入**：`joint_tarawa_wargame.py` 串联上述三个子模型，按用户给定的多阶段战役序列（空袭→登陆分拦截/炮击队→夜间水面战→拂晓陆攻→跨越轰炸→潜艇互攻→丁型驱逐舰+潜艇撤运）做蒙特卡洛累计。它**不引入新物理**，只把子模型的标定输出按战役逻辑串接；子模型的边界在此同样适用。 |
| **输出性质** | 蒙特卡洛**概率分布**（沉没率、重创率、退出率、逐舰下场、空战交换比），不是单场确定性剧本。 |

---

## 二、不适用（Out of scope）

| 维度 | 原因 |
|------|------|
| **航空作战的闭环在线控制**（俯冲轰炸 / 水平轰炸 / 飞行员手感投弹） | 那是"**人在回路的在线控制**"——飞行员持续修正投弹瞬间，命中率 15–33%，与本模型的"开环预测"机理完全不同，需另建控制回路模型。**注意**：飞机**投雷几何**（`aerial_torpedo_fem.py`）与**dogfight 能量/回转机动**（`aircraft_dogfight_fem.py`）已以"开环几何＋战斗参数"纳入——它们算的是"给定投放状态下的命中/交换比分布"，不模拟飞行员闭环操控手感。 |
| **反潜（ASW）/ 水雷 / 两栖登陆 / 电子战软杀伤** | 不在水面炮–雷对抗的建模范围内。 |
| **剧烈规避机动**（蛇形 / 急转 / 变速） | 本模型假设匀速直线；真实规避会显著改变散布与命中，未建模。rangekeeper 本身也假设目标匀速直线。 |
| **人的因素**（指挥意志、训练偶然性、士气） | 仅作为**参数输入**（如 `jp_torp_quality`、`us_torp_quality`、照明弹有无），**不预测**。 |
| **单场确定性预测** | 本模型是统计分布。它告诉你"大概率怎样"，不保证"这一场必然怎样"。 |

---

## 三、关键假设与边界条件

1. **干扰因子由史实锚点反推**：照明 / 识别 / 火控中断 / 观测虚报等"吃掉 60–70% 能力"的因子，
   是用华盛顿→雾岛 12%、雾岛→南达 1.7% 两个锚点反推的。**锚点若有误，反推因子随之偏移。**
2. **来源分级**（见 README 数据分级表）：独立机构复核 > 行业区间 > 参战方单方通报。
   参战方数字只作方向与量级，不作精确值（申报通胀是传感器损坏，不是宣传问题）。
3. **双方同时核算**：任何对比都同时给日方与美方数字，不单向列举（只列一方损失 = 宣传，不是分析）。
4. **200 次蒙特卡洛，种子固定**（`seed=42`）：结果逐位可复现；同种子两次运行一致 ⇒ 确定性成立。
5. **比例风险**：模型给的是"相对战力损失 %"与"沉没均值"，不是绝对舰船数。

---

## 四、一句话总结

> **这个模型回答的是"在给定装备、训练、夜战条件下，命中率与战损的概率分布"，
> 而不是"历史必然如此"。** 它是推演 / 兵棋研究的量化工具，不是史官。

任何把模型输出当作"某场海战一定会这样打"的用法，都超出了它的适用边界。
