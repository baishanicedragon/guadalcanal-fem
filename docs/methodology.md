# 方法论：先算"干净弹道底"，再反推干扰因子

本仓库所有命中率数字都遵循同一条铁律：

> **先按真实弹道表算出"干净底"（仅武器本身散布 + 火控误差 + 匀速平台扰动），
> 再用真实"实测锚点"反推干扰因子（照明 / 识别混乱 / 火控中断 / 观测虚报 / 引信可靠性）。**

不拍脑袋给命中率；每个数字都往上可追到弹道表、往下可追到史实锚点。

---

## 1. 舰炮 FEM（`gunnery_fem.py`）

目标：战列舰 vs 战列舰 夜战炮击命中率。

组成函数：
- `tof(d)`：真实飞行时间表线性插值。标定用表：
  - US 16"/45 Mk6 + AP Mk8：MV 701 m/s，TOF 6.83s@4.5km / 14.45s@9.1km / 22.94s@13.7km / 32.55s@18.3km / 43.61s@22.9km。
  - JP 46cm Type94 + 91 式 AP：MV 780 m/s，TOF 26.05s@16.8km / 49.21s@27.9km / 70.27s@35.8km / 89.42s@40.7km。
- `speed_gun_factor(own, tgt, stable)`：航速→炮击命中率。
  - 夜战匀速前进保光学测距 → 平台扰动非剧烈规避。
  - 美方（雷达 + 陀螺）温和惩罚（约 0.6%/kt）；日方（纯光学无陀螺）敏感（约 1.2%/kt + 二次项）。
  - BB 炮击航速封顶 18 节（超出按 18 节计）。
- `sigma_total(d)`：散布椭圆（随射程放大）+ 火控解算误差。
- `clean_floor(d, radar)`：矩形命中判定（目标投影面积 / 散布椭圆面积）。

**干净底结果**（含匀速平台扰动）：
| 距离 | 雷达火控（美方） | 光学（日方） |
|------|----------------|-------------|
| 8 kyd | 32.2% | 5.7% |
| 15 kyd | 12.3% | 1.7% |
| 20 kyd | 7.2% | 0.9% |

**反推干扰因子**：用史实锚点
- 华盛顿 → 雾岛 ≈ 12%（雷达侧，@约 8–9 kyd）
- 雾岛 → 南达科他 ≈ 1.7%（光学侧，@约 8–9 kyd）

干净底 32%→实测 12%、5.7%→实测 1.7%，意味着**夜战混乱吃掉了约 60–70% 的真实能力**。
这一"吃掉"正是模型要反推的干扰因子（照明缺失、识别混乱、火控中断、观测虚报）。

## 2. 鱼雷 FEM（`torpedo_fem.py`）

目标：驱逐舰直线雷对匀速移动编队的命中率。

- 直线雷 3° 散布；45 节航行 15–20 km 抵达 18–24 节匀速编队（舰间距约 500 yd ≈ 457 m）。
- `torp_hit_rate(D, Vt_kt, N, cls, n=4000)`：per-any（命中整编队任一舰）与 per-target（命中指定目标）。
- `_torp_clean_p(dist)`：干净几何底（@18km per-any ≈ 44%、per-target ≈ 7.4%；3° 散布仅偏移约 943 m，远小于编队半宽 1829 m）。
- `_torp_slowdown(speed_frac)`：中弹减速 = 最致命（#17）。per-target 满速 4.1% → 停车 8.9%（×0.55→×1.20）。
- **可靠性因子**（引信 / 定深）：Type93 ≈ 0.80（接触引信可靠、浅定深）；Mk-15（1942）≈ 0.07（磁引信灾难性失效、深弹道）。
  → 实测差异几乎全在**引信与定深可靠性**，不在几何。

## 3. 整场推演主模型（`mc_fem.py`）

按用户时间轴逐拍推进（肖特兰出航 → 21:30 照明弹 → 三川诱饵 → 战列进入奇袭窗口 → 23:40 93 式齐射 → 23:45 Mk-15 反击 → 23:55 持续炮战 → 00:15 大和支援 → 00:45 岸轰）。

- `torpedo_strike` 的鱼雷命中率已用 §2 的 FEM 标定（干净底 × 可靠性 × 舰型 × 减速因子）。
- `is_jp` 标志贯穿 `schedule_torp → flush_torp → torpedo_strike`，确保日方走 93 式（装药因子 1.10）/ 美方走 Mk-15（0.90），标签与毁伤因子一致。
- 航速炮击因子接入 `single_shot_p`（`own/tgt` 航速封顶 18 节）。
- `SPEED_KT` 去重：设计/巡航最高速（追击判定）与 BB 炮击 18 节上限分离。

## 4. 可复现性（铁律 #16）

每个数字都带 **命令 + 参数 + 日期**：

```bash
cd src
python report_200.py        # run_sim(scenario, n=200, seed=42)
# 版本：mc_fem.py（含 torpedo_fem 标定 + _speed_gun_factor 接入 + SPEED_KT 去重）
# 日期：2026-09-23
```

蒙特卡洛用固定种子（`seed=42`）保证逐位可复现；同种子两次运行结果一致 ⇒ 确定性成立。
引用任何数字前，先确认"它是哪个版本、哪条命令跑出来的"。
